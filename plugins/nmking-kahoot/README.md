# Kahoot!

NMKING 發行的獨立連線指南外掛。可個別安裝、停用及更新，不安裝其他服務。

此外掛僅提供 Skill 和文件，不包含 MCP 伺服器設定，也不會自動登入。非服務供應商官方外掛。

安裝命令：

```sh
codex plugin add nmking-kahoot@nmking-plugins
```
